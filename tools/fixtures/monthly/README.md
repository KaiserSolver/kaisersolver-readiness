Everything here is generated by `tools/make_fixture.py` for the tests. It runs the real
cow-backtester code path (`main()`, the rows, the `_meta` lines, the readiness report) with the
network leaves patched out: chain RPC, S3, the solver and the competition API are stand-ins, and one
public auction (8339027) is cloned into 43 auctions.

- The transaction hashes are invented, and the submitter addresses are dummies
  (`0x...0d0c0a` is "ours", `0x...0abc` is the rival).
- The timestamps and block numbers are placed outside any month this record covers.
- The numbers say nothing about any solver. Do not cite them.

Regenerate with `PYTHONPATH=<cow-backtester checkout> python3 tools/make_fixture.py --out tools/fixtures/monthly`.
